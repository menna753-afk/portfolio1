## 🚀 How to Deploy & Get Your Public URL

Deploying this website is 100% free, takes under 2 minutes, and gives you a public link you can share on your CV, LinkedIn, and social media.

### Method 1: Netlify Drop (Fastest — No installation needed, ~30 seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop) (sign in or sign up with GitHub / Google).
2. Drag and drop the entire `portfolio` folder directly onto the upload box on Netlify.
3. Netlify will deploy it in seconds and give you a public live link (e.g. `https://menna-geramy.netlify.app`).
4. You can customize the site name in **Site configuration > Change site name**.

---

### Method 2: GitHub Pages (Directly connected to your GitHub profile)
Because your GitHub username is `menna753-afk`, you can host your site directly under your GitHub account!

1. Create a new public repository on GitHub called `portfolio` (or `menna753-afk.github.io`).
2. Run these commands inside `C:\Users\lap_shop\.gemini\antigravity-ide\scratch\portfolio`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Menna Geramy Portfolio"
   git branch -M main
   git remote add origin https://github.com/menna753-afk/portfolio.git
   git push -u origin main
   ```
3. On GitHub, go to your repository **Settings** > **Pages** (on the left menu).
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Within 1 minute, your site will be live at:
   ```
   https://menna753-afk.github.io/portfolio/
   ```

---

### Method 3: Vercel (1-Click Deployment)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **Add New... > Project**.
3. Import your `portfolio` repository.
4. Click **Deploy** (a `vercel.json` file is already pre-configured).
5. You'll instantly receive a fast, worldwide CDN link like `https://menna-geramy.vercel.app`!
